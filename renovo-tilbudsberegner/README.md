# Renovo tilbudsberegner

Vejledende prisoverslag til forsikringsskader og genopbygning for **Renovo ApS**.

## Kør lokalt

```bash
cd renovo-tilbudsberegner
npm install
npm run dev
```

Åbn den viste lokaladresse (typisk `http://localhost:5173`).

## Byg

```bash
npm run build
npm run preview
```

## Indhold

- Trinvis beregner: skadetype → omfang → fag → tillæg → kontakt
- Vejledende prisinterval inkl. moms
- Estimeret varighed
- Kontaktformular (demo – gemmer ikke til backend)

Priserne er illustrative og erstatter ikke besigtigelse eller forsikringsopgørelse.

Hero-foto: Unsplash (byggeplads), bundlet lokalt i `public/hero.jpg`.
